# v2.1.0

- Windows가 실행 파일의 경로를 다르게 표현하는 환경에서도 업데이트 파일을 정상 확인하도록 수정했습니다.
- 이미 종료된 서버의 상태 파일이 남아 있어도 다음 실행이 불필요하게 대기하지 않도록 보완했습니다.
- 현재 실행기에 이미 같은 버전이 들어 있으면 동일한 실행기를 다시 띄우지 않아 시작 과정의 압축 해제를 한 단계 줄였습니다.
- 업데이트 성공 후 현재·이전 복구 버전과 실행 중인 프로그램을 보존하고 오래된 프로그램 캐시를 정리합니다. 알 수 없는 파일이나 연결된 폴더는 삭제하지 않습니다.
- 실행·업데이트·서버 로그는 파일당 1MB, 이전 기록 2개로 용량을 제한합니다.
- 설정, 임시 저장, 자료 검색, 일지 쌍 저장을 별도 모듈로 분리했습니다. 일지 계산과 HMI 연결 규칙은 유지합니다.

프로그램은 계속 EXE 하나로 배포합니다. 설정·입력값·업무 자료는 캐시 정리 대상에 포함하지 않습니다.
