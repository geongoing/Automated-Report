# v2.0.0

- EXE 실행 시 새 정식 버전을 자동 확인하고 업데이트합니다.
- 업데이트 프로그램은 AppData에서 관리하며 EXE 옆에 폴더를 만들지 않습니다.
- 다운로드 검증과 새 프로그램 시작 확인이 실패하면 기존 버전을 사용합니다.
- 일지 생성 중에는 업데이트를 미뤄 작성 중인 파일을 보호합니다.
- 설정에 현재 버전·업데이트 확인·변경 내용 보기를 추가했습니다.
- 기존 설정, 임시 입력값, 최종 일지와 HMI는 유지합니다.
- 최초 사용자는 ZIP 안의 `일지작성.exe` 하나를 꺼내 실행하세요. v1.x 사용자는 이 EXE로 한 번 교체하면 됩니다.
