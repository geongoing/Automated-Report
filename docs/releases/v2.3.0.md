# v2.3.0

- 일지 파일을 최종 이름으로 저장한 직후 오류가 나거나 오류 정리 중 프로그램이 종료되는 경우의 복구를 보강했습니다. 이번 요청이 만든 파일을 저장 전에 기록하여 기존 자료를 보존하면서 안전하게 처리합니다.
- 엑셀의 숫자·시트·공유 문자열이 손상된 경우 해당 파일을 목록에서 제외하고, 직접 처리할 때는 문제가 있는 시트와 셀을 안내합니다.
- 연속 입력을 잠시 모아 임시 저장하여 불필요한 디스크 기록을 줄였습니다. 브라우저에는 즉시 보관하며, 생성·종료 시 전송과 저장 실패 후 복원을 유지합니다.
- 잘못된 로컬 요청 주소 형식을 오류 응답으로 처리하도록 보강했습니다.
- 월말·연말·윤일의 날짜 연결, 모든 이월·계산 및 HMI 셀 매핑, 저장 중단과 임시 입력 복구의 자동 검증을 확장했습니다.

업무 계산식, D20 원본 유지, 화면 구성과 기존 파일을 보존하는 재작성 방식은 그대로 유지합니다.
