# v2.2.0

- 폴더 설정과 날짜별 임시 입력값의 최근 정상 저장본 3개를 자동 보관합니다. 파일이 없거나 손상되면 검증을 통과한 최신 백업에서 복원하며, 손상된 원본 사본도 남깁니다.
- 최종 일지·HMI는 먼저 완성된 임시 파일로 저장하고 검증한 뒤 최종 이름으로 게시합니다. 기존 파일은 덮어쓰지 않습니다.
- 저장 중 프로그램이 강제로 종료되면 다음 실행에서 복구 기록과 파일 내용을 확인해 누락된 일지 저장을 이어서 완료합니다. 정상적인 저장 오류는 이번 요청이 만든 변경 없는 파일만 되돌립니다.
- 폴더 연결이 끊겼거나 기존 파일 내용이 달라졌으면 복구를 보류하고 해당 파일을 보존합니다. 같은 경로·기록일의 새 생성은 복구 문제를 해결한 뒤 진행합니다.

백업과 복구 기록은 사용자 데이터 폴더에 보관하며 EXE 옆에 추가 폴더를 만들지 않습니다.
